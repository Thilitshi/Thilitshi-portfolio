# Personal Portfolio with AI Chatbot

A responsive personal portfolio website showcasing my background, technical skills, projects, certifications, and experience. The website also includes an AI-powered chatbot that allows visitors to interact with an assistant and learn more about my work and portfolio.

## ✨ Features

- 👤 Professional profile and introduction
- 💼 About Me section
- 🛠️ Technical skills and technologies
- 🚀 Project showcase with project images
- 🎓 Certifications section
- 📄 Resume/CV access
- 📬 Contact section with LinkedIn and GitHub
- 🤖 AI-powered chatbot
- 📱 Responsive design for desktop, tablet, and mobile
- 🔐 Environment variables for API and database credentials

## 🛠️ Tech Stack

| Layer | Technologies |
| --- | --- |
| Frontend | HTML5, CSS3, JavaScript |
| Backend | Python, FastAPI |
| Database | MySQL |
| AI | Google Gemini / OpenAI |
| Database Access | SQLAlchemy, PyMySQL |
